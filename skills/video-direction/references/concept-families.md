# Concept families [R-01 R-02 R-13 G-09]

Starting points, not templates. Every piece writes 3 fresh concepts for its own brief and material; the chosen one is designed from scratch (own opening frame, timing, shapes, type).

Per concept record: `name`, `idea` (1 sentence about the picture), `carry`; also state opening frame, what it rules out, look (palette + type).

## Generic

| Family | Idea |
|---|---|
| Transforming object | One object transforms through every beat (envelope → card → CTA button). |
| Scale camera move | Detail → pull back to place → push into the phone number. |
| Cause and effect | Each beat triggers the next. |
| Physical metaphor | Postcard written, key turning, ticket torn. |
| Typographic system | The words are the set. |

## Photo-led (places, rooms, a day out)

| Family | Idea | Carries |
|---|---|---|
| Window | One framed window changes shape (arch → landscape → circle); next place opens from a point of the previous photo (door, steam, ray). | outline + opening point |
| Postcards | Cards fall on a table, squash, stack, nudge, resolve into a grid around the logo. | the pile |
| Day arc | Disc of light crosses morning → night; each place opens with an iris born from the disc. | disc + its colour |
| Trail | Photos pinned in a larger world; camera walks a drawn path that draws itself. | camera + trail |
| Living map | Map with pins; each card opens out of its pin and folds back. | map + pins |
| Coffee to evening | One day in photos/clips, ending on a frozen frame that becomes a cream postcard. | time of day, then frozen frame |
| Entering | First-person walk, one continuous gesture: door → inside → detail → lit window → view. | the single camera move |
| Small details | 2×2 grid of close-ups/micro-clips, one word each, closing on one large still. | grid, then growing cell |
| Logbook | Handwritten travel journal; a written hour opens each beat; the ink stroke draws the next scene. | page + ink line |
| Key | Each turn of a key unlocks the next place; ends on open door with contact. | key + rotation |
| Written postcard | Back fills with cursive, stamp is a photo, flip reveals the place. | card, written → picture side |
| Light clock | One still view; only its light moves morning → night; no cuts, nothing travels. | the frame |
| Before / after rest | Split screen grey city vs the place; place's half pushes the seam until it owns the frame. Show rest, never promise an effect. | the seam |
| Match cut | Each place ends on a shape the next repeats in the same spot (round table → cup rim → setting sun). | shape + position |
| Object wipe | Something crosses the lens (towel, branch, door frame, hand) and uncovers the next place. | wiping object + direction |
| Film strip | Negatives slide through; one frame develops into colour and grows into the scene; strip curls into logo. | the strip |
| Scrapbook | Album page being made: taped photos, ticket, pressed leaf, script labels; camera drifts over a growing page. | the page |
| Chain reaction | Every beat causes the next (pine cone → ripple frames photo → steam blows the page…). | the cause, always visible |
| Dive through scale | One continuous zoom region → river → complex → deck → cup (or out). No pins, no cuts. | anchor point, fixed on screen |
| Calendar | Desk calendar pages tear off, each reveals a place; last page blank "your dates" + contact. | calendar block |
| Letters as windows | Huge headline, each letter a window onto a photo; camera flies through a counter into the next place. | letterforms |
| Thread | Brand-colour thread runs through every scene, wraps objects, ties a bow on logo/gift card. | the thread |
| Depth | Photo split into planes moving at different speeds; dolly through foreground into next photo. Needs layer masks. | camera + nearest plane |
